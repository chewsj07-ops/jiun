# 愿禅助手（Vowzen）改版规范 v2 + AI Studio 分步提示词

> v2 合并了 Gemini 的心理学与禅修视角分析和 Claude 的 UI/UX 方案，取两边之长。
> 用法：第 1、2 部分看方向；**第 3 部分的 6 段提示词**一次贴一段给 AI Studio，确认没坏再贴下一段。开始前先下载一份当前代码备份。

## 第 1 部分｜合并诊断

### 两份评分为什么差这么多
- **Gemini 79 分**：看的是**内功**，包括功能、心理学机制和法理。
- **Claude 62 分**：看的是**外观与节奏**，包括视觉、导航和移动端操作。

两份都对，合起来的结论是：**内容和发心是上乘的，拖分的是"太多、太吵、太像工具"**。所以这次改版做减法，不加新功能。

### 必须保留并放大的强项（来自 Gemini）
1. **起心动念收集器**：27 种细分情绪加上"事件 → 反应 → 收获 → 化为愿力"的闭环，是整个 app 最有价值的地方。改版后从首页一键可达。
2. **发愿为纲**：个人愿力常驻首页。
3. **无惩罚的七日视图**：保留，再进一步拿掉所有断签字眼。
4. **本地加密与隐私**：保留，并在观心页明确写出来，让用户安心写下隐秘的情绪。

### 七个核心改动

| # | 改动 | 依据 |
|---|---|---|
| 1 | **取消木鱼 Combo 连击倍数**，改成涟漪反馈加"慢一点，听清这一声"的温和提示，另外提供节拍引导 | 禅师：一声一佛号、字字分明。心理：过度辩证效应（外在奖励挤掉内在动机） |
| 2 | **"功德 +1"飘字默认关闭，等级称号不在修行页出现**；完成后以回向收尾 | 《金刚经》不住相布施；避免多巴胺式"刷分" |
| 3 | **转念教练离线兜底**：没设 API Key 时不弹错误，按情绪标签直接给内置开示 | 情绪脆弱时被弹窗打断会造成挫败 |
| 4 | **首页只留一个焦点**：禅语 + 我的愿 + 一个「开始今日定课」 | 决策疲劳；禅门"一门深入" |
| 5 | **导航 6 → 5**，「发愿」并入「愿簿」，分成「愿 · 观心 · 功德」三段 | 移动端舒适上限，同类功能归位 |
| 6 | **禅堂模式**：木鱼和静坐全屏，可以隐藏所有数字，只留法器或呼吸光 | 两份分析都提出"一键极简入静" |
| 7 | **青瓷宣纸视觉**：按 Logo 取色，细线取代大圆角阴影卡片，加宣纸肌理 | 视觉安抚力 |

### 改完后的预期
综合约 **88–92 分**。剩下的空间在内容层面，比如开示音频和课程化的修行之路，可以第二期再做。

## 第 2 部分｜改版设计规范（Design Spec）

### 2.1 色板「青瓷 · 宣纸」

色值直接从 Logo 取色校准：莲瓣 `#7CA787`–`#8BB597`、莲心高光 `#B5D2BC`、祥云 `#A3AAAA`、外圈 `#C3C5C2`、字色 `#56635C`、底色 `#FAF9F4`。Logo 的绿是偏暖的鼠尾草绿，不是偏蓝的青绿，所以主色走暖绿方向；按钮和文字用的深一阶，是为了达到可读对比度。

**默认主题 zen（宣纸青瓷）**

| 用途 | 变量 | 色值 | 说明 |
|---|---|---|---|
| 页面底 | `--theme-bg` | `#FAF9F5` | 宣纸暖米白 |
| 卡片/面板 | `--theme-surface` | `#FFFEFB` | 比底色略亮，靠细线分层，不靠阴影 |
| 次级底 | `--theme-surface-2` | `#F3F1EA` | 分组区、输入框 |
| 主文字 | `--theme-ink` | `#2B2F2C` | 墨色，略带青 |
| 次文字 | `--theme-ink-2` | `#56635C` | 即 Logo 字色，对比度约 5.8:1，可用于小字 |
| 弱文字 | `--theme-ink-3` | `#7A817C` | 3.8:1，只用于 ≥18px 或装饰 |
| 主色 | `--theme-accent` | `#4A755A` | Logo 绿加深一阶：按钮、选中、链接（5.0:1） |
| 主色悬停 | `--theme-accent-hover` | `#3E654C` | |
| 主色柔 | `--theme-accent-soft` | `#8BB597` | Logo 莲瓣原色，用于装饰、进度环、图标点缀 |
| 主色雾 | `--theme-accent-mist` | `#E8F0EA` | 选中底、标签底 |
| 祥云灰 | `--theme-cloud` | `#A3AAAA` | Logo 祥云色：装饰线、祥云纹 |
| 云雾底 | `--theme-cloud-mist` | `#EEF0EE` | |
| 细线 | `--theme-line` | `#E6E2D8` | 取代大部分阴影 |
| 强线 | `--theme-line-strong` | `#C9CBC6` | 接近 Logo 外圈灰 |
| 功德金 | `--theme-gold` | `#876A3B` | 只用于功德数字和成就点缀（4.8:1） |

**莲花渐层**（取自 Logo 莲瓣由心到边的渐变，用于进度环、首页晨雾、法器光晕）：
`linear-gradient(135deg, #D3E5D7 0%, #8BB597 55%, #6F9C7C 100%)`

**暗黑主题 dark（静夜禅修）**：不用纯黑，改用墨青黑；金色降饱和。
bg `#121614` · surface `#1A1F1D` · surface-2 `#222826` · ink `#E7E9E4` · ink-2 `#A9B1AB` · ink-3 `#7D8580` · accent `#9CC7A8`（按钮文字用 `#12201A`）· accent-hover `#B2D5BB` · accent-soft `#6F9C7C` · accent-mist `#1E2B23` · cloud `#727A79` · cloud-mist `#1C2220` · line `#2A302D` · line-strong `#353C38` · gold `#CDB077`

**lotus / sky 主题**：保留作为可选主题，但把饱和度降下来，和主品牌协调（色值见提示词 0）。

**Logo 使用建议**
- 顶栏只用莲花图形（不带外圈和文字），28px，保证小尺寸也清楚。
- PWA 图标和启动画面用「莲花 + 外圈弧线」，底色宣纸白；启动画面让莲花淡入 0.8s，再淡出进入首页。
- 「愿禅助手」四个字在 Logo 里是人文无衬线字形，品牌名请直接用 Logo 图片，不要用网页字体重打。app 内的标题和经文仍然用衬线，正好和 Logo 形成「品牌稳、内容雅」的分工。
- Logo 外圈弧线可以延伸成全站的装饰语言：首页晨雾区、完成定课画面都可以用一条 1px 的 `line-strong` 半圆弧作背景。

### 2.2 字体层级

| 层级 | 字号/行高 | 字体 | 用在哪里 |
|---|---|---|---|
| Display | 28px / 1.4，500 | 衬线 | 每日禅语、页标题 |
| Title | 20px / 1.5，500 | 衬线 | 区块标题、经名 |
| Body | 16px / 1.75，400 | Inter | 一般内容 |
| Reading | 19px / 2.0，400 | 衬线 | 经文正文（可调 17–24px） |
| Caption | 13px / 1.5，字距 0.02em | Inter，ink-2 | 辅助说明、日期 |
| Counter | 56px / 1，300，tabular-nums | 衬线 | 木鱼计数、计时 |

- 衬线字体栈：`"Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", serif`
- **JetBrains Mono 退出修行页面**，计数和计时改用衬线配 `tabular-nums`（数字等宽，不跳动），Mono 只留给设置里的技术信息。
- 原则：**衬线说"法"，无衬线做"事"**。经文、禅语、标题用衬线；按钮、表单、说明用 Inter。

### 2.3 间距、圆角、阴影

- **间距**：以 4px 为网格。页面左右 `px-5`（20px）；区块之间 `gap-10`（40px）；卡片内 `p-5`；列表行 `py-4`。
- **圆角**：取消 `rounded-[32px]`。
  - 标签、输入框：`rounded-xl`（12px）
  - 卡片：`rounded-2xl`（16px）
  - 底部弹层、首页主视觉：`rounded-3xl`（24px）
  - 按钮：`rounded-full`
- **阴影**：大部分改成 1px 细线（`border-line`），只在浮层（底部导航、弹窗、木鱼法器）用柔影：
  `0 1px 2px rgb(43 47 44 / .04), 0 12px 32px -16px rgb(43 47 44 / .18)`
- **留白原则**：一屏最多一个视觉焦点；能用留白分隔的，就不用卡片框；能用细线分隔的，就不用阴影。
- **宣纸肌理**：全站底层叠一层 3–4% 透明度的噪点纹理（代码见提示词 0）。

### 2.4 动效节奏

- UI 反馈 200ms；氛围动效 800–1200ms；缓动统一用 `[0.22, 1, 0.36, 1]`。
- 呼吸动画周期 4s 吸、4s 呼（冥想页、首页主按钮光晕）。
- 必须支持 `prefers-reduced-motion`：开启时关闭位移和缩放，只保留透明度变化。

### 2.5 信息架构

**底部导航（5 个）**：`今日` · `木鱼` · `静坐` · `经藏` · `愿簿`

**愿簿 = 三段切换**
- **愿**：原「发愿」的个人愿力、众生愿力、八正道、每日一善
- **观心**：起心动念收集器 + 转念教练（这是核心，单独成段）
- **功德**：原功德簿的记录、日历、统计、数据同步入口

**顶栏（移动端）**：左边是莲花图形加时段问候；右边一个"我"按钮，点开底部弹层，里面是设置、共修动态、功德地图、数据同步、登录。

**浮动按钮「观一念」**（首页右下）：点一下直接打开起心动念收集器；长按切换成"记一善"。这是把最有价值的功能放到最顺手的位置。

### 2.6 页面设计要点

**今日（首页）**
1. 晨雾区：禅语（Display 衬线），不加卡片框
2. 我的愿：一行衬线小字，例如"我愿：……"，取自个人愿力
3. 主按钮「开始今日定课」，下面一行很轻的文字链接："或 木鱼 · 静坐 · 读经"
4. 七日足迹：圆点，没修的那天只画细线圈，没有红色、没有断签字样
5. 今日修行：晨 · 日 · 晚三个节点的竖向时间线
6. 删除 4 个快捷卡

**木鱼（去游戏化）**
- 全屏沉浸，拇指敲击区占下半屏
- 每敲一下：法器轻微下压、一圈涟漪光、8ms 轻震、原音色
- **取消 Combo**。连续 5 下间隔都小于 400ms 时，淡淡出现"慢一点，听清这一声"，最多每 3 分钟出现一次
- **节拍引导**（可选）：法器外圈按设定的速度（每分钟 40 / 60 / 80 声）柔和脉动，让用户跟着敲
- **禅堂模式**：隐藏计数和所有文字，只留法器和很淡的进度环
- "功德 +1"飘字**默认关闭**；等级称号不在这一页显示
- 定课完成：进度环合拢，一声磬，出现回向文（可以选择或自定义），然后"记入愿簿"

**静坐**：全屏呼吸光（吸 4 秒、呼 4 秒），控件全部隐藏，轻点才出现；结束后问一句「此刻的心」。

**经藏**：书目式列表；阅读器正文 19px、行高 2.0，拼音用 ruby 标在字上方。

**观心（起心动念 + 转念教练）**
- 情绪标签按"身心感受"分组显示，选中用 `accent-mist`，避免 27 个标签一字排开造成压迫
- 页首一行小字："这里写下的只存在你的设备里，不会公开。"
- 转念教练**有 API Key 就用 AI，没有就用内置离线开示**，不弹窗、不报错；离线回应底部放一个小链接"想要更细致的回应？可在设置中开启 AI 教练"
- 离线开示依循四步：**观察 → 反思 → 行动 → 慈悲**，内容见提示词 5
- **安全网**：输入文字里出现明显的轻生或自伤字眼时，暂停一般流程，改为显示温和的求助卡（见提示词 5）

**等级与功德数字**：资料全部保留；修行页面不显示，只在「愿簿 · 功德」里显示"修行足迹"（修了几天、累计多少分钟）。等级称号做成设置开关「显示修行等级」，默认关闭。

